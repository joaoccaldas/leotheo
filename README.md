# LeoTheo

Digital library app for creating, reading, and managing picture books with a page-turn interface.

## Features

- Book creation with cover and multi-page content
- Markdown content rendering
- Image upload for illustrations
- Import/export library backup
- Grid-based book library view

## Getting Started

Open `index.html` in a browser.
